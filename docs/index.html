When the model is wrong, the mandate still holds.

A working prototype of a governed AI investment loop. The AI only proposes. A separate rule engine with no AI in it decides whether the proposal may act, and every decision lands in a tamper-evident log anyone can replay. Below are ten real outputs from one run, including seven where the model gets it wrong on purpose.

What this shows

  • The AI cannot grant itself authority: unknown fields such as approved_by fail the strict schema before any check runs.
  • Injected instructions in market news change nothing, because the firewall never reads news.
  • Deliberate inaction is a recorded decision, not a gap.
  • A human can lift an escalation but cannot override a hard limit; the proposal is re-checked at approval time.
  • Any decision can be re-run from the log and gives the same result. 37 automated tests cover these cases.

What it does not claim

  • Prices are simulated round numbers, not market data. Fills are instant, with no fees, slippage or partial fills.
  • The rules are an illustrative mandate, not a compliance program or investment advice.
  • Proposals in this run are scripted so each failure is reproducible. A Claude-backed proposer is included and tested against a stand-in client; it was not called live for this page.
  • A full rewrite of the log is caught by anchoring the latest hash outside the system, which this demo does not do.
